# QBR Template — jfrog.com Digital Strategy

## Slide-by-Slide Structure

### Slide 1: Title
- "jfrog.com Digital Strategy — Q[X] [Year] Business Review"
- Presenter name and date

### Slide 2: Executive Summary
Three sentences maximum:
1. Overall quarter performance (above/below/at target)
2. Biggest win and its impact
3. Biggest challenge and what's being done about it

### Slide 3: Scorecard
Full KPI table with status indicators:

| Category | KPI | Q Target | Q Actual | Status | QoQ Trend | YoY Trend |
|----------|-----|----------|----------|--------|-----------|-----------|
| **Acquisition** | Total Sessions | | | | | |
| | Organic Sessions | | | | | |
| | New Users | | | | | |
| **Engagement** | Engagement Rate | | | | | |
| | Avg. Engagement Time | | | | | |
| **Conversion** | Trial Signups | | | | | |
| | Demo Requests | | | | | |
| | Pricing Page CVR | | | | | |
| **SEO** | Share of Voice | | | | | |
| | Organic Keywords Top 10 | | | | | |

### Slide 4: Wins
Top 3-5 accomplishments, each with:
- What was done
- Quantified result
- Why it matters

Format: **[Action]** → [Result] → [Business impact]

Example: **Redesigned pricing page** → 18% lift in trial signups → est. $XXK pipeline impact

### Slide 5: Challenges & Learnings
Honest assessment:
- What didn't hit target and why
- External factors (algorithm changes, market shifts)
- Internal factors (resource constraints, dependencies)
- Lessons learned for next quarter

### Slides 6-8: Initiative Deep Dives (1 per initiative)

Specific decisions or resources needed from leadership:
1. [Ask] — [Why] — [Impact if approved/denied]

### Appendix
Backup slides with:
- Detailed data tables
- Methodology notes
- Full project timelines
- Competitive benchmarks
- Team capacity/allocation

## Preparation Checklist

- [ ] Data pulled and validated (GA4, BrightEdge, Profound)
- [ ] Scorecard populated with actuals vs. targets
- [ ] Win stories drafted with quantified impact
- [ ] Challenge narratives reviewed for tone (honest but constructive)
- [ ] Initiative deep dives drafted with before/after data
- [ ] Next quarter priorities aligned with leadership expectations
- [ ] Asks are specific and include impact framing
- [ ] Appendix prepared for anticipated questions
- [ ] Dry run completed with at least one colleague
